# Buzdolabı Magnetleriyle Uluslararası Barış Konferansı

> **Türkiye Cumhuriyeti Hayali Buzdolabı Diplomasisi Genel Müdürlüğü**  
> Belge No: BD-2026-KONF-0042  
> Gizlilik: Açık ama kimse okumaz

Bu yazılım, evinizdeki buzdolabının kapağında toplanmış magnetlerin dünya barışını görüşmesini simüle eder. Kod **gerçekten çalışır**. Barış **gerçekten gelmez**. Bu bir özelliktir.

## Neden bu proje var?

Çünkü mutfak diplomasisinin Birleşmiş Milletler'den daha dürüst olduğu bilimsel olarak kanıtlanmamıştır ama biz yine de denedik. Magnetler:

- birbirini itmez (fizik yalan söyler)
- küresel ısınmayı buzdolabının içinden tartışır
- karar alır, sonra o kararı pizza kuponunun altına saklar

## Kurulum

```bash
python3 konferans.py
```

Bağımlılık yoktur. Sadece Python 3 ve bir miktar sabır.

## Kullanım

Program sizden bir gündem maddesi ister. Örnekler:

- `sütün son kullanma tarihi`
- `dondurucu kapısının sıkışması`
- `dünya barışı (lütfen kısa tutun)`

Sonra delegeler konuşur. Delegeler:

| Delege | Yetki Alanı |
| --- | --- |
| Mandalina Magneti | Turuncu diplomasisi |
| Pizza Kuponu Magneti | Gıda güvenliği ve indirim |
| Aile Fotoğrafı Magneti | Nostalji lobisi |
| Eczane Saat Magneti | Zaman yönetimi |
| Kedi Sticker Magneti | Bağımsız gözlemci |

Oylama yapılır. Sonuç her zaman "erteleme"dir. Bu da bir özelliktir.

## Teknik not

- Rastgele konuşmalar `random` ile üretolir.
- Konferans tutanağı ekrana basılır.
- Hiçbir magnet BM üyesi değildir.
